# 小秘书效果稿 v2：时间格直接操作（PROTOTYPE）

> 2026-11-02 后续决定：一小时固定四个 15 分钟格已由“默认 10 分钟、粒度可调整”取代；本文其余内容保留为历史原型背景。

> 问题：上一版像后台系统。这一版只验证「时间块式布局 + 现代 app 的直接操作」是否足够顺手。仍是单文件 throwaway prototype，不是生产代码。

## 用户已明确选择的方向

- 主画布采用时间块 App 的纵向网格：**一小时是一行，一行固定 4 个 15 分钟格**。
- 时间是主对象，标签是标记时间的工具；不是任务列表、日历 event 卡片墙或 BI dashboard。
- 主闭环：**选择格子 → 点击标签 → 立即着色**。不用“新增计划块”按钮，不先打开表单，不使用开始/结束秒表。
- 现代 app 交互：直接点选/拖选、点击块弹出轻量编辑浮层、即时生效、可撤销、有克制的过渡反馈。
- 保留计划、实际、对照、独立统计和精力，但它们不得破坏时间画布的安静与连续性。

## 必须推翻的上一版设计

当前 `index.html` 只是 negative reference（反面参考），允许并鼓励完全重写：

- 删除大号页面标题、说明性 hero、 eyebrow 文案。
- 删除常驻 KPI 卡片行。
- 删除厚重的三层页面标题 / 工具条 / 内容容器。
- 删除常驻编辑侧栏表单和“保存记录”式后台交互。
- 删除整周七列密集 event 卡片墙；周计划通过星期切换查看同一天网格。
- 不用大表格作为默认对照首屏，不用营销页风格，不用夸张渐变和玻璃拟态堆叠。
- 不要把 A/B/C 做成三套后台 dashboard。

## 统一产品结构

单个 `index.html`，无外部运行依赖，状态只在内存。默认浅色，可切深色。默认打开 `?variant=A` 的「实际」时间画布。

顶部只保留一行紧凑工具条：

- 左：小秘书名称 / 小图标，计划 / 实际 / 对照的轻量 segmented control。
- 中：上一天、日期（2026 年 10 月 27 日，周二）、下一天；计划模式显示一周 7 天的紧凑日期 strip，强调“每周重复”只用一行小字或 tooltip。
- 右：统计、标签管理、主题三个图标按钮。图标有 `aria-label` 与 tooltip。
- 当日总记录时长可作为低强调 inline meta，不做 KPI 卡片。

主区域占据首屏 80% 以上：纵向可滚动时间画布，小时刻度 sticky/清晰，当前时间线可作为参考。初始滚动到 08:00 左右。

## 时间画布硬约束

每个变体都必须满足：

1. **一小时一行、每行 4 格**，对应 `:00 / :15 / :30 / :45`；不是每小时一条大 event，也不是 30 分钟一行。
2. 每行左侧为小时刻度，中间是一条窄而独立的精力色带，右侧为四格事项区。
3. 空格有细腻但清楚的边界；hover 显示可标记状态；选中格有明确高亮。
4. 连续记录可跨格、跨小时显示，但仍能感知 15 分钟网格。跨小时时可以分段显示，底层仍是一条记录。
5. 同一格允许两条并行记录：在格内分成上下两条 lane（展示轨道），不能另起后台式“任务列表”。
6. 记录块颜色来自一级类别；二级为稳定同色系变体。文字尽量直接压在色块上，短块可只显示名称或通过 tooltip 查看。
7. 空白选择支持点击和连续拖选；至少实现同一小时拖选，最好支持跨小时拖选。
8. 选择后点击标签立即标记；已选多块时显示总时长。
9. 点击已有记录选中整条记录，并出现轻量 contextual popover / action bar：可改标签、备注、精力、删除；修改即时生效，无需保存按钮。
10. 支持撤销（按钮与 Cmd/Ctrl+Z），删除或覆盖后出现短暂 undo toast。
11. 最好支持拖动记录按 15 分钟移动；若实现，必须真的可拖，不要放无功能装饰手柄。

## 三个真正不同的直接操作变体

三版共用相同数据、时间网格和主要功能；底部保留小型 `PROTOTYPE` 变体切换器，URL `?variant=A|B|C`，支持左右键且输入框聚焦时不拦截。

### A · 标签架（默认，最接近时间块）

- 左侧/中间为大时间画布，右侧约 260–300px 的**标签架**。
- 标签架不是编辑表单：一个搜索框 + 一级类别分组 + 可点击的彩色标签按钮；二级内容缩进或小一号。
- 未选格时标签架低强调并提示“拖动时间格，然后点标签”；选中后立即可用。
- 当前记录详情用选中块附近的 popover 或底部 contextual bar，不把右栏变成表单。
- 这是桌面端推荐变体。

### B · 纯净画布

- 默认没有右栏，时间画布更宽、更安静。
- 拖选空格后，在选择附近直接弹出紧凑标签 picker；点击已有记录也使用同一浮层。
- 顶部只保留一个“标签”入口用于浏览/管理。
- 适合希望最少 UI 的用户；浮层不能超出视口，Esc 可关闭。

### C · 底部快捷标记

- 时间画布为主，底部是触摸友好的常驻标签 dock（一级类别 + 当前类别二级内容，可横向滚动）。
- 选格后底栏抬起并显示“已选 1 小时 30 分”，点标签立即标记。
- 点击记录后底栏切换为操作上下文；不做侧栏表单。
- 底部变体切换器不得遮挡标签 dock，可放左下角或缩小。

## 计划、实际、对照、统计

### 计划

- 同样的一日小时四格画布；顶部星期 strip 切换周一到周日。
- 表示每周重复模板，切换具体周仍展示同一模板；不引入单日任务状态。
- 计划记录和实际记录数据独立，编辑一侧不改变另一侧。

### 实际

- 默认视图，直接补记实际时间。
- 示例至少包含通勤 + 听课程并行、临时沟通、刷手机、带备注的记录。
- 当前时间只是细线，不自动产生记录。

### 对照

- 默认日双画布：共享小时刻度，计划与实际并排；每侧仍是一小时一行、四格、并行 lane 和独立精力色带。
- 可切换“分类差异”，以简洁的横向差值条 + 时长/构成比显示，不做 BI 卡片墙。
- 显示 Planned、Actual、Δ = Actual − Planned；构成比模式显示 Δpp。
- 不显示完成率，不跨轨配对，不使用红绿评价差异。
- 窄屏用计划/实际切换，不硬压双画布。

### 独立统计

- 通过右上角统计按钮打开大型 sheet / 非模态覆盖视图，而不是后台 dashboard 常驻页面。
- 根据打开前的计划/实际模式使用对应数据源，标题明确“计划统计”或“实际统计”。
- 日/周/月范围切换；总记录时长、构成比、平均值、横向条形图和轻量趋势图。
- 视觉仍简洁，不用四个 KPI 卡片开场；可一行 inline summary + 两个图表区域。
- 明确“记录时长”，并行记录分别累计。

### 标签管理

- 用 sheet / dialog 按需打开；支持新增、重命名、删除示例。
- 删除被引用标签时显示影响并阻止静默删除。
- 不让管理界面成为主页面。

## 精力

- 精力带位于小时刻度与事项四格之间，是独立窄带，不占事项标签。
- 深度时间、碎片时间、低谷三类即可；有图案/文字或 tooltip，不只靠颜色。
- 点击精力带可标注；计划和实际各自保存，不同步。
- 提供显示/隐藏按钮，但入口轻量，不做大工具条。
- 对照时两侧各自保留精力带。

## 视觉与动效

- 方向：现代个人生产力 app，接近 TimeBlock 的轻量直接感，可借 Apple Calendar / Things / Linear 的克制，不复制其导航。
- 默认温暖中性浅色背景，彩色时间块成为主要视觉焦点；深色同样可用。
- 小圆角、细边界、柔和阴影只用于 popover/sheet；不要每张内容都套卡片。
- 字体用系统字体，13–15px 为主；减少大标题和全大写英文。
- 100–180ms 的选格、着色、popover、toast 过渡；支持 `prefers-reduced-motion`。
- 不用 emoji 充当主要图标；用 inline SVG。
- 390px 下无横向页面溢出，四格仍清晰；标签架变为 bottom sheet/dock。

## 示例数据

一级：工作（蓝）、学习（绿）、生活（橙）、娱乐（紫）。二级：工作/写作、工作/沟通、学习/课程、生活/通勤、生活/运动、娱乐/刷手机，另保留学习/阅读。

计划与实际必须有差异：

- 08:00–09:00 通勤 + 听课程并行。
- 09:30–11:30 写作。
- 11:30–12:00 沟通。
- 14:00–15:30 工作或课程。
- 18:00–19:00 运动。
- 实际增加临时沟通、刷手机；计划有阅读但实际没有。
- 至少一条备注“整理小秘书原型反馈”。

## 验收

- A/B/C 都能选格、点标签着色、编辑、删除、撤销、切换计划/实际/对照、打开统计。
- 1 小时严格 4 格；并行、跨小时、精力、备注可见。
- 无后台式大标题/KPI/常驻编辑表单。
- Popover 与 sheet 支持 Esc，焦点和视口位置合理。
- 390px 无横向溢出，底部元素不互相遮挡。
- 最终直接完成 `index.html` 并做基本浏览器检查，不要只输出计划或设计说明。
