# 小秘书-时间块

本文描述当前 TimeBlock 产品的功能与交互。产品入口、Remote 和装卸见 [Time 产品包 README](../../packages/time-panel/README.md)；日期、Tags、计划和实录的领域规则见 [Time 领域包 README](../../packages/time-block/README.md) 与 [数据模型](../data-model.md)。

## 入口与模块

TimeBlock 位于 DSH 右侧栏，标题为“小秘书-时间块”。当前包含三个平级的一级模块，都从头部左侧的模块切换区（图标 + 名称）打开的抽屉进入：

- **实录**：查看和维护 ActualBlock。
- **计划**：查看和维护具体日期的 PlanBlock。
- **深度时间**：维护独立的 7×24 精力周模板。

计划模板、开始／停止实录、Tag 管理和统计没有当前画布入口；对应已有领域能力仍可经 Agent tools 使用。

## 画布与日期导航

- 画布使用固定 **10 分钟**一格、每小时六格，连续展示多天。进入时读取今天前后的一段日期窗口，滚动到边缘时扩展窗口并保持当前阅读位置。
- 行高随可视高度调整，让一天尽量占满一屏；空间不足时使用画布内部滚动，但不显示滚动条。当前日期有标记，当前时刻用画布内的指示线表达。
- 顶部日期跟随当前阅读位置。左右按钮分别移动一天，`今天` 回到当前日期；点击日期打开自绘月历，可跨月跳转。
- `←`／`→` 步进一天，`PageUp`／`PageDown` 步进一周；输入框和文本编辑区域不拦截这些按键。
- 深度时间使用同一套导航外观，但按周步进；`本周` 回到当前周，日期选择器选择整周。

## 模块切换

三个一级模块在同一个抽屉里切换，没有再嵌套的二级菜单。在实录与计划之间切换时，保留正在阅读的日期，不改变另一层的事实；两者都使用当前日期窗口，但写入只影响所选层。

## 选区、上色与擦除

1. 单击未选中的格会追加选区；单击已选中的格只取消该格。
2. 拖动选择同一天内的连续区间；不同日期的选区可以累计，画布底部的浮动徽章显示总时长。
3. 点击右侧时间标签后，所选区间通过 Remote 写入对应层，并立即清空本地选区。标签架支持层级展开与收起。
4. `Esc` 只清空本地选区，不修改事实。
5. `Delete` 或 `Backspace` 对选区执行擦除，而不只是取消选择。

时间块与深度时间共用同一套选区操作：单击切换、拖动成段、`Esc` 清空、`Delete` 擦除；不再有底部按钮栏。

上色会切割选区覆盖的既有块、保留未选中部分、写入新块，并合并相邻同形块。领域允许任意重叠；默认上色会覆盖选区中的既有内容，需要保留它们时改用下面的并行模式。

时间块的读取与显示支持任意并行。重叠格只显示按开始时间、创建顺序最靠前的一条记录，右上角出现数量角标；点击角标展开该格的全部记录（颜色、名称、起止时间、时长），默认收起；点浮层外或按 `Esc` 收起；点外部仍按原行为选格，`Esc` 仍按原行为清空选区。并行不增加行高、不横向切分格子，也不把多条记录画成多轨或跨格色带。

选区覆盖到已有记录时，浮动选区徽章会多出 `覆盖｜并行` 切换，默认 `覆盖`；选区存在时按 `Tab` 可在两者间切换。选 `并行` 后点标签，保留选区覆盖的全部旧记录，并在整个选区新增一条记录；写入成功后回到 `覆盖`。普通覆盖不增加这一步。

Remote 失败不会显示成功，也不会把失败操作加入 Undo。已成功写入的内容在页面重载和进程重开后仍可读取。

## 记录备注与删除

在已上色的块上右键，打开该记录的备注页；重叠格先点数量角标选择具体记录，再进入该记录的备注页：

- 修改备注。
- 删除该记录。

换标签不经过备注页：选格后直接点标签架即可覆盖；调整起止时间也通过重画完成。保存成功才关闭备注页；失败时保留输入并显示错误；删除成功后才提示完成。当前不提供拖动记录移动或拖动边缘调整区间。

## Undo

- 标题栏的 Undo 只覆盖上色和擦除，不覆盖深度时间、编辑或删除。
- 栈按后进先出保存最近 50 次操作；一次操作可包含多个日期的快照，Undo 逐日恢复。
- 栈只在当前产品会话内有效，完整重开后不保留。
- 多日恢复中途失败不会显示“已撤销”，也不会把已弹出的操作自动重新入栈。

## 深度时间

- 页面显示一周七天、每天 24 小时的格子，可点选或拖出矩形选区；周网格复用时间块的固定背景渐变，未设置格透明。
- 选择 `高 / 中 / 低` 写入选区；`Delete` 或 `Backspace` 清除为未设置，`Esc` 只清空选区。
- 当前周没有自己的记录时，会继承最近的有效更早周，最多回溯 52 周；编辑只写当前周，不改被继承的周。
- 未设置不等于 `low`，可以只使用 `high`。深度时间不从实录派生，也不因实录变化而改写。

## 规划中（尚未实现）

以下能力已确认方向，但尚未完整进入当前画布。本文只写产品意图与交互规则；实现规格与验收由 tracker 承载：

- **并行时间块的单条调整与范围擦除**（#7；显示、并行写入与单条删除已落地，规则见上文）：
  - **调整并行**：点击数量角标展开记录列表，点选具体记录后再编辑；起止时间按 10 分钟步进调整，标签与备注也只作用于该记录；不允许在主画布上拖动被遮住的并行记录。
  - **范围擦除**：单条删除已从角标浮层进入；`Delete` 命中并行时仍会一次清空选区内全部记录，后续需要先提示将影响几条记录，确认后才清除选区内部，选区外不动。
  - **不变的交互**：单击格子仍是选中／取消；拖动仍是选择时间范围；默认上色仍是覆盖；普通记录右键备注、`Delete` 与 `Undo` 不变；深度时间不变。
  - **不做**：不增加并行显示设置、主副标记、自动轮换或隐藏开关；并行是数据事实，不是视图模式。
  - **已否决**：格内横向 N 等分、按小时加行或多轨、错层卡片、层叠摘要、行下清单，以及早期的标签优先两态画笔；最终采用固定格阵＋数量角标＋浮层选记录。
- **计划模板**：按星期维护复用模板，显式应用到具体日期；应用后仍可单独调整该日计划，不回写模板、不修改实录。
- **开始／停止实录**：用原子能力形成一段实录，不自动完成 GTD Action。
- **Tag 管理入口**：统一维护 `time` / `context` 两棵标签树的管理界面；当前只有标签架和 Agent tools。

## 主题与布局

颜色、表面和焦点使用宿主 token，支持宿主明暗主题。产品保持窄右栏布局，在 390px 宽度下仍使用同一套操作，不另建独立页面或路由。时间块内容随宿主侧栏宽度自适应；DSH 深色主题使用参考材质（近黑页、中灰渐变网格），浅色主题继续跟随宿主。网格区的背景渐变固定在可视区，不随日期上下滚动移动。DSH 头部直接接在宿主导航下、不留独立缝隙，画布可滚动但不显示滚动条。
