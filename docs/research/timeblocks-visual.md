# iPhone「时间块」深色界面视觉提取

- 提取对象：用户提供的 iOS「时间块」深色截图（589 × 1280 JPEG，见 [reference-2026-11-08-dark.jpg](assets/timeblocks/reference-2026-11-08-dark.jpg)）。
- 提取目的：只抽取可迁移到 dsh-secretary TimeBlock 的视觉语言，不复制业务交互，也不把 iOS 专有布局当成产品契约。
- 方法：按截图像素取样颜色、量取比例，再折算到 390 CSS px 宽的时间块右栏；颜色值取同色区域中位数，四舍五入到最近的色值。
- 边界：一张图不能证明该 App 其他页面、动效或主题；本文只描述这张截图可见的视觉。

## 1. 一句话结论

它的质感来自三个非常克制的手段：**近黑底 + 中灰满格网格 + 低饱和暖色大色块**。没有阴影、没有卡片、没有渐变；层级只靠明度、留白和圆角。

## 2. 颜色

按截图取样，折算到 sRGB：

| 角色 | 取样值 | 说明 |
|---|---|---|
| 页面 / 画布底 | `#000000` | 画布、右侧栏、日期栏都是纯黑 |
| 顶栏 | `#151515` | 比画布略亮一档，靠明度区分而非分割线 |
| 空格网格 | `#505050` | 整格填充中灰，不是描边网格 |
| 网格分隔线 | `#000000` | 与页面同色的 1px 线，切出“黑色缝” |
| 主文字 | `#FFFFFF` | 日期、时间刻度、类别名 |
| 次文字 | `#AFAFAF` 附近 | “(今天)”、图标的次要状态 |
| 暖黄类别 | `#FFCD6E` | 学习、技术；投资理财略浅，约 `#F3E5B8` |
| 正红类别 | `#E63643` | 投资 |
| 深红类别 | `#852024` | 工作 |
| 珊瑚红类别 | `#F06060` | 生活、交通、娱乐 |
| 中性类别 | `#4D4D4D` | 休息、睡觉 |
| 选中 / 当前 | `#FFFFFF` | 只是白线、白描边，不引入彩色高亮 |

观察：

- 类别色是**低饱和暖色**，不是 iOS 系统蓝绿；同一屏里大量重复珊瑚红，靠文字区分而不是靠色相区分。
- 按钮和记录块的色面不是完全平涂：用户确认移动端有轻微上下渐变；截图取样接近平涂是因为压缩与幅度很小。实现时用约 10% 白 → 透明 → 8% 黑的上下渐变模拟，不做过亮高光。
- 黄色上的文字仍是白色，说明它的第一优先级是“色块的整体感”，不是文本对比度。迁移到通用产品时要补 contrast 策略，不能盲抄。
- 没有使用品牌蓝做焦点色；焦点、当前时间、下划线都是白色。

## 3. 几何

按 589 px 图宽、390 CSS px 视口折算（约 1.51×）：

| 元素 | 截图比例 | 折算 CSS | 备注 |
|---|---|---|---|
| 网格左边距 | ≈ 105 px | ≈ 69 px | 日期 + 小时刻度共用 |
| 网格宽 | ≈ 305 px | ≈ 202 px | 6 列，每列 ≈ 34 px |
| 行高 | ≈ 47 px | ≈ 31 px | 24 行一屏；与时间轴一致 |
| 类别栏宽 | ≈ 179 px | ≈ 118 px | 占约 30% |
| 类别按钮高 | ≈ 50 px | ≈ 33 px | 10 个按钮 + 间距刚好一屏 |
| 类别按钮圆角 | ≈ 10 px | ≈ 6–7 px | 大圆角是暖感的主要来源之一 |
| 类别按钮间距 | ≈ 12 px | ≈ 8 px | 不使用卡片容器，按钮直接浮在黑色上 |

- 网格是 6 列 × 24 行的连续矩阵；单元格之间没有间隙，只有黑色分隔线。
- 日期栏不画卡片、不画边框；月份、日、星期、今天四行直接排在黑底上。
- 右侧类别栏没有背景容器，按钮直接贴在黑色背景上。

## 4. 字体与排版

- 日期：月份约 11 px、日号约 34–36 px 加粗、星期约 11 px，整组左对齐；“今天”下方一条约 2 px 白色下划线，作为当天标记。
- 小时刻度：`0:00`…`23:00`，等宽数字，约 10 px，右对齐，白色/浅灰；不是现在常见的只写 `0`。
- 类别按钮：约 13 px、常规偏中等字重、白色；左内边距约 10 px。
- 全局字族是系统无衬线（SF / PingFang），没有衬线或装饰字体。
- 没有卡片标题、说明副标题或图标堆叠；信息密度高，靠留白分组。

## 5. 组件规则

1. **空格就是灰块**：空单元格用中灰填充，黑色 1px 分隔；画布因此始终是“有内容的矩阵”，而不是一张空表。
2. **记录就是实色块**：记录/类别用整格实色填充，不使用浅底 + 左边条 + 阴影的卡片式表达。
3. **类别按钮是纯色圆角条**：无描边、无阴影、无渐变；宽度固定，高度一致，文字左对齐。
4. **状态只用白色**：选中、当前、下划线、描边统一白色；不引入第二种强调色。
5. **没有浮层装饰**：顶栏、画布、类别栏平铺在同一黑色底上，层级靠 `#000 / #151515 / #505050` 三段明度。

## 6. 可迁移与不可迁移

**适合迁移到 dsh-secretary 的部分**

- 空格填充 + 黑色分隔线的矩阵质感。
- 近黑页面 / 抬升一档的顶栏 / 纯黑类别栏的三段明度。
- 大日号 + 月份 / 星期 / 今天 + 白色下划线的日期块。
- 无边框、无阴影、大圆角的暖色类别按钮。
- 白色作为唯一焦点色。

**不应直接照搬的部分**

- iOS 顶栏（菜单、标题、印章、对照图标、状态栏）属于宿主壳，不属于 TimeBlock 模块。
- 固定手机宽度和固定一屏 24 行是参考 App 的布局；我们的右栏宽度可拖拽，行高需要自适应。
- 类别色是参考 App 的用户数据；我们只能把参考色作为 **fixture / 默认建议**，生产标签色仍来自 Tag 数据。
- 黄色底 + 白字对比度不足；迁移时需要按标签亮度决定文字色，或给文字加轻微暗描边，不能无脑照抄。

## 7. 对 TimeBlock 的初步设计指令

- 画布：`--tb-grid-cell` 使用中灰（暗色约 `#4A4C50`，浅色约 `#E3E5E9`）；单元格分隔线取页面底色，形成 1–1.5px 的黑色/浅色细缝，并覆盖在记录块之上，保证相邻色块之间也有缝。
- 表面：页面近黑、顶栏略亮、类别栏取页面色；不要给类别栏或画布加卡片容器。
- 日期：日号放大到 30–36 px；月份、星期、今天用小字；当天加白色下划线。
- 小时刻度：改为 `H:00`，使用等宽数字；左边距允许略增。
- 类别按钮：去掉内描边，圆角 6–7 px，字号 13 px，内边距 10 px；参考色只进入 fixture 调色板。
- 选中/当前：继续用白色描边和白色时间线，不新增彩色焦点。
