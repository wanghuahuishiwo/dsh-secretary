# Glossary

## Language

**动作（Action）**:
小秘书唯一的事项实体，可以逐级拆解为子动作。持续存在的父动作与一次具体的课程、工作或活动都使用 Action；一次具体动作独立完成，父动作继续存在。

**预计时长（Estimated Duration）**:
动作的可选估计，只作为安排参考；未知时不填，不作为实际时长、完成条件或固定排程约束。

**完成（Completion）**:
动作自身的独立状态，不由子动作的完成状态自动推导，也不由计划时间结束自动推导。

**计划时间（Planned Time）**:
具体动作当前预计发生的时间段，可以在执行前调整；不是实际发生的事实。

**实际时间（Actual Time）**:
具体动作实际发生的时间段，不从计划时间自动生成，也不因计划变化而回写。

**时间板块（Time Category）**:
描述时间类型的分类体系，与 Action 的事项归属无关；是时间画布着色和时间构成统计的主维度。

**时间块（Time Block）**:
带有计划或实际时间的具体 Action 在时间网格中的展示单位，不是独立的事项实体。

**准备（Preparation）**:
Secretary Agent 在具体动作发生前，为其整理所需上下文与材料的行为；不规定固定材料流水线。

**DSH Schedule**:
宿主提供的持久定时任务与提醒能力，只负责在指定时间向原会话投递提示；不是小秘书的日历安排或事项实体。
