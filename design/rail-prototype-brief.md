# 右边栏交互原型（时间块版）

> PROTOTYPE：只回答「界面长什么样、手势怎么走」，数据在内存，刷新复原，不进生产代码。
> 打开：`design/rail-prototype.html`（深色默认；抽屉里 → 设置 → 点一下切明暗）。

## 这一版改了什么（相对上一版）

上一版把 Time 做成了「DSH 主面板里的全宽画布 + 右侧标签架」。这一版把整个秘书产品搬进 **DSH 右边栏**（`@deepseek-ai/dsh-client-ui-sidebar-right` 的 tab），并且 Time 的交互**照 iPhone「时间块」App 的模型重做**，不再用自创的画笔/消除态。

依据：`docs/research/timeblocks-interaction.md`（App Store 官方文案 + 官方截图数格 + 一手用户记录）、`docs/research/omnifocus-ios-navigation.md`（OmniFocus 官方手册 + 4.0 发布说明）。

## 外壳

- 宿主给一条 tab strip（`秘书 | 文件 …`），strip 以下**只有一行我们自己的头**：`模块名 ⌄`，右侧两个按钮（提示、撤销）。点模块名从**左边滑出抽屉**。
- 抽屉＝一级模块：时间块 / 深度时间 / 事项 / 目标 / 标签 / 统计 / 设置，中间用分隔线分组，当前项高亮。点 scrim、Esc、选中任意项都关闭。
- 抽屉和底部浮层（备注/编辑）是**全局复用的两种容器**：GTD 的 Sidebar、Inspector 也走这两个，不再另造层级。

## 时间块（照 App 复刻的部分）

| 元素 | 复刻结论（有来源） | 本原型 |
| --- | --- | --- |
| 格阵 | 一小时一行，行内横向 N 格：30 分钟 2 格 / 15 分钟 4 格；跨小时必然阶梯状 | 15 分钟 4 格 |
| 记录手势 | **两步制**：先点格子选中（可连点累积），再点右侧类别赋值；底部反馈「选择了 X 分钟」 | 拖＝选一组格，再点类别；单击空格＝选一格 |
| 删除 | 只有橡皮，单击已有块是「选中」不是清除 | 选中后点橡皮 |
| 改类别 | 选中块再点另一个类别 | 同 |
| 备注 | 选中块 → 底栏 → 备注 | 底栏「添加备注」→ 底部浮层 |
| 浏览器 | 单列竖向连续多天、日期块、零点虚线、当前时刻线 | 同 |

本产品多出来的两处（原型里已实现，需你确认）：

1. **计划 / 实录两层**：标签架顶部切 `实录 | 计划`。实录模式下，计划画成每小时行顶部 3px 细条（看得见计划、不挡实录）；计划模式下计划整块显示、实录变淡。
2. **时间精度**：App 没有起止时间、不能拖块；我们的数据是真起止时间，所以在备注浮层里留了 `−/＋` 各调 15 分钟，不引入拖动块。

## 事项（结构改了，照 OmniFocus 4 手机端）

调研结论推翻了「逐层下钻」这个方案：OF4 iOS **没有**透视列表→列表→详情这种 push，它是**大纲即主页 + 底部透视条 + 可召唤的 Sidebar / Inspector**，行内就地编辑，没有单条任务详情页。所以窄栏里做 GTD 不用牺牲形状：

- 顶部一行透视 chips（收件箱 / 项目 / 今天 / 预测 / 回顾，带计数）。
- 下面是缩进大纲：项目行可折叠（带未完成数），动作行＝状态圈 + 标题 + 项目·日期，点行**就地展开**编辑卡（标题、项目、标签、时间、备注），点圈完成。
- 项目树/标签过滤走同一个左侧抽屉，检查器走同一个底部浮层。

## 明确没做

- 深度时间只画了周模板网格（点/拖换档），没做「应用到某天/撤销应用」。
- 标签页只列出现有 12 个时间标签，没做增删改拖拽层级。
- 印章、统计、趋势、目标、设置只有入口或占位。
- 不做真实写库；不涉及 Agent 主动准备。

## 已验证

- Chromium 驱动：拖选 3 格 → 底栏出现「选择了 45 分钟」→ 点「阅读」→ 记录落到 03:00–03:45 且底栏消失；点已有块选中整条（底栏显示类别+备注入口）；橡皮删除；撤销恢复；抽屉开合；事项行内展开；明暗两套无 page error。
- 桌面 1280×900 与窄窗 980×820 均无横向溢出。
