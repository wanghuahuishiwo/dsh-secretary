# Time 与 Tag 可丢弃原型

> PROTOTYPE：只回答界面与直接操作问题，状态在内存，不连接真实数据，不进入生产代码。
> 2026-11-03 用户已选择 **A · 标签架**；B／C 仅保留为本次探索的历史对照。

## 要回答的问题

1. 时间标签放在右侧标签架、选区旁浮层或底部快捷栏，哪种最顺手？
2. 周计划、具体日期实录和深度时间能否在同一个 Time 工作区里清晰切换？
3. 统一 Tag 管理能否只增加“时间 / 情境”切换，而不产生两套交互？

## 三种方案

- **A · 标签架**：桌面端时间画布 + 右侧时间标签树，标记入口始终可见。
- **B · 纯净画布**：默认只显示时间画布，拖选后在选区旁出现标签。
- **C · 底部快捷标记**：时间画布 + 底部标签 dock，强调连续点按与触摸操作。

通过 `?variant=A|B|C`、底部切换栏或左右方向键切换；输入框聚焦时不拦截方向键。

## 共同验收路径

1. **日期计划**：与实录使用同样的具体日期导航；点击日期文字打开月历，可跨月选任意日期，箭头逐日微调；小长假可直接编辑。“计划模板”是独立入口，应用后互不回写。
2. **时间实录**：按 2026-11-02 浏览；计划与实录数据独立；同一时段可有多条记录。
3. **时间格**：默认 10 分钟，可切 15／30 分钟；小时行高 48px；切换粒度后既有时间块不变。
4. **两态操作**：标记态下，格内没有当前标签就添加为并行，已有当前标签就直接消除；双击右侧已选标签进入消除态，可点击／拖刷消除任意记录，单击标签退出；Shift + 点击才编辑。
5. **深度时间**：独立 7×24 周模板；选择 `high / medium / low` 画笔，连续拖刷，同档起手清除。
6. **Tag 管理**：时间／情境共用一个入口和一套字段；新增、重命名、删除、调整层级，时间标签变化同步到画布。
7. **主题与布局**：明暗主题可用，390px 无横向页面溢出。

## 已验证（2026-11-03）

- JavaScript 语法通过；OpenDesign lint：P0／P1／P2 均为 0。
- Chromium + Playwright 完成 **74/74 项交互断言**：三种方案、日期计划、独立模板、月历跨月选择、回到今天、两态添加与消除、计划／实录隔离、撤销、深度时间、Tag 管理、主题及移动端布局。
- 日期专项覆盖：月历跨月选择、逐日微调、日期栏与月历均可回到真实的今天并高亮；不同日期各自保存；模板应用后不回写，也不写入实录。
- 浏览器无 page error；390px 无横向页面溢出。
- 导入产物与仓库 HTML 的 SHA-256 完全一致。
