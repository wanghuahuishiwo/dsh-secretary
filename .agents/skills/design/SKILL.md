# design

按需求 Issue 做出可评审的设计实现。

1. 读需求 Issue，再读项目入口说明里的设计契约、构建方式和预览入口。
2. 在 UI 与设计壳范围内改动，按设计契约组织组件与样式；设计需要新的数据形状时，作为待决项写回 Issue。
3. 构建，按项目说明给出预览入口，确认预览能打开。
4. 提交并 push 到独立分支，开或更新 PR。
5. 把分支与 PR 链接、commit、改动、预览入口、待确认点写回 Issue 评论。

完成标准：PR 中的改动可以构建并预览，Issue 评论里能直接找到预览入口和待确认点。
