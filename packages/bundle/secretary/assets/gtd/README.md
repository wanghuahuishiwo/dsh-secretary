# 小秘书 GTD 数据目录

本目录是小秘书的 GTD 数据面：自由 Markdown，任何 DSH agent 或人（含 Obsidian）都可直接读写。没有专用工具、没有数据库。

## 文件

| 文件 | 用途 |
|---|---|
| `Inbox.md` | 收件箱。捕获的原始条目先落在这里，澄清后移走。 |
| `GTD.md` | 项目与行动。澄清后的承诺按项目归位在这里。 |
| `notes/` | 长备注与准备结果，主文件里用相对链接引用。按需出现。 |
| `assets/` | 附件。按需出现。 |

## 格式约定

- **checkbox = 行动状态**：`- [ ]` 待办，`- [x]` 完成。
- **缩进 = 层级**：子行动缩进到父行动之下。
- **Obsidian 式标签 = 属性**：写在行尾，如 `#工作`、`#due/2026-12-01`、`#est/90m`。未知标签不报错。
- **标题 = 项目**：`GTD.md` 中每个 `##` 段是一个项目，段首可写一句 Outcome；不属于任何项目的独立行动放在 `## 独立行动`。
- **长内容走链接**：长备注、准备清单、议程放 `notes/` 下的独立文件，主文件只留一行链接。

## 读写约定

现读现写、写前重读、写后回读。没有缓存和监听：任何人（包括 Obsidian 里的用户）改完，下一次读取就是最新内容。时间块与标签不是 Markdown，经 DSH 会话内的 CLI（`$DSH_SECRETARY_CLI`）读写，详见 secretary skill。
